# Selection Pro (Next.js 16 + React 19 + TypeScript)

## Run (Next.js 16, works in Termux with the webpack flag)
```bash
npm install
npm run dev          # next dev --webpack  -> http://localhost:3000
npm run build        # next build --webpack
npm start
```
`--webpack` is needed on Termux/Android because the native Turbopack/SWC binaries are not available there (Next falls back to WASM).
If a version clashes during `npm install`, copy the `next`, `react`, `react-dom` versions from your other working project (`apps/web`).
Deploy on Vercel as-is (it will use its own native compiler; you may remove `--webpack` from the scripts there if you like).

## Structure
- `src/app` pages (App Router), `src/components` UI, `src/lib` helpers, `src/data` editable content, `src/content` converted articles and indexes
- `public/practice-tests`, `public/data`, `public/tests`: your question JSON files (chapter files renamed to url-safe slugs)
- Old `.html` URLs redirect permanently to the new clean URLs (see `next.config.mjs`), so Google rankings and shared links keep working

## Adding content
- **Current-affairs notes:** edit `src/data/ca-entries.ts` (summary in your own words + exam angle + possible questions). They appear automatically.
- **New practice test:** drop `xyz_pt_NN.json` in `public/practice-tests/` and add its entry to `src/content/tests.json` (same shape as the existing ones).
- **New GK / trap questions:** `src/data/quiz-bank.ts`.
- **Exam syllabus / FAQ:** `src/data/exams-extra.ts`.
- **Ads:** `public/ads.txt` is included. Set `NEXT_PUBLIC_ADS_ENABLED=true` only after AdSense approval.

## New features
Daily quiz with streak, MCQ trap of the day, mistake notebook (spaced repetition), syllabus tracker with countdown, personal dashboard, per-test topic analysis and negative marking, timer, question palette, retry-wrong, dark/light mode, global search (Ctrl+K), JSON-LD (FAQ, Breadcrumb, Article, Quiz, Course), sitemap.xml and robots.txt generated by Next.
